For this assignment, I learned how to make API calls and use my API key as part of
a data pipeline. One of the first and most important steps is to create a
`.env` file and add the key as `CENT_API_KEY`. This helps keep the API key private.
I also learned about the differences in the code for making API calls. For
example, in `apicalls.py`, it's important to send the right kind of data. For
JSON, use `json=` rather than `data=` in the `requests.post()` arguments. One
thing that was challenging in this assignment was the `pipeline.py` section.
`pipeline.py` introduced caching, which I still don't completely understand. We
were supposed to cache the responses returned by the APIs. After looking into
caching, I learned that it means storing a copy of an API response in a fast,
temporary storage layer. To understand how caching is used in practice, I can
continue working with API calls and use the `cache_file` argument. I think I
need to spend more time calling APIs and using them in code.
