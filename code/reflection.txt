For this assignment, I learned how to make API calls and use my API key as part of
a data pipeline. One of the first and most important steps is to create a `.env`
file and add the key using the `CENT_API_KEY` variable. This helps protect the
key from being used without permission. I also learned that API calls can require
different types of request bodies. For example, in `apicalls.py`, it is important
to send the right kind of data. For JSON, use `json=` rather than `data=` in the
`requests.post()` call.
